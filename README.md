# pricing-site

Static pricing pages for Kntara, served with GitHub Pages.

The `index.html` files are **generated** — don't hand-edit them. They are built
from a single pricing source in the main Kntara repo; change the price there and
regenerate, so every page stays consistent.

```
index.html      holding page
hours/          pricing page
simple/         pricing page
team/           pricing page
robots.txt      search engines excluded
```
